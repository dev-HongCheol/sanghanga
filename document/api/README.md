# 키움 REST API 문서 가이드

이 디렉토리는 `kiwoom-api-docs.xlsx` 엑셀 파일을 파싱하여 자동 생성된 마크다운 API 명세서를 포함하고 있습니다. 모든 문서는 AI(Gemini/Claude)가 참조하여 코드를 구현하기 최적화된 형식으로 구성되었습니다.

## 📂 폴더 구조

API 문서는 엑셀의 분류 체계에 따라 **대분류 > 중분류** 구조로 저장됩니다.

```text
document/api/
├── OAuth 인증/           # 인증 및 토큰 관련 API
│   ├── 접근토큰발급/
│   └── 접근토큰폐기/
├── 국내주식/             # 국내 주식 관련 핵심 API
│   ├── 시세/
│   ├── 주문/
│   ├── 계좌/
│   ├── 종목정보/
│   └── ...
├── ETF/                 # ETF 관련 API
├── ELW/                 # ELW 관련 API
└── index.md             # 본 가이드 파일
```

## 📄 문서 구성 형식

각 API 마크다운 파일(`.md`)은 다음과 같은 섹션을 포함합니다:

1.  **API 정보**: 메뉴 위치, API 명, ID(TR 코드)
2.  **기본 정보**: HTTP Method, URL, 운영/모의투자 도메인 정보
3.  **개요**: API 기능 설명
4.  **Request**: Header 및 Body 파라미터 (타입, 필수 여부, 설명 포함)
5.  **Response**: 응답 필드 상세 구조
6.  **Examples**: 실제 요청 및 응답 JSON 샘플 (코드 구현 및 테스트 시 참조)

## 🚀 API 문서 업데이트 방법

엑셀 파일(`document/prd/api-parser/kiwoom-api-docs.xlsx`)이 업데이트된 경우, 아래 스크립트를 실행하여 마크다운 문서를 동기화할 수 있습니다.

### 실행 명령어
```powershell
pnpm dlx tsx scripts/api-parser.ts
```

### 스크립트 특징
- **목차 기반 탐색**: 엑셀의 첫 번째 시트(목차)를 분석하여 생성할 API 목록을 결정합니다.
- **자동 분류**: 대분류와 중분류 정보를 읽어 폴더 구조를 자동으로 생성합니다.
- **데이터 정제**: 엑셀 특유의 줄바꿈이나 깨진 인코딩 문자를 정제하여 깔끔한 마크다운을 렌더링합니다.
