# Grid Trader 호가 단위 조정 가이드

> Grid Trader의 호가 단위 자동 조정 로직 설명

## 📋 개요

한국 주식시장은 가격대별로 정해진 **호가 단위**가 있으며, 키움증권 API는 호가 단위에 맞지 않는 주문을 거부합니다. Grid Trader는 이를 자동으로 처리합니다.

## 🎯 한국 주식 호가 단위

| 가격대 | 호가 단위 |
|:-------|:----------|
| 1,000원 미만 | 1원 |
| 1,000원 ~ 5,000원 | 5원 |
| 5,000원 ~ 10,000원 | 10원 |
| 10,000원 ~ 50,000원 | 50원 |
| 50,000원 ~ 100,000원 | 100원 |
| 100,000원 ~ 500,000원 | 500원 |
| 500,000원 이상 | 1,000원 |

## ⚙️ 조정 방식

### 1. 그리드 계산 단계 (`calculateGrid.ts`)

```typescript
// 입력
현재가: 123,456원
그리드 간격: 5,000원

// 처리 과정
1. 현재가 조정: 123,456 → 123,500원 (호가 단위 500원으로 반올림)
2. 간격 조정: 5,000원 → 5,000원 (이미 500원 배수)
3. 그리드 계산:
   - 매수 1: 123,500 - 5,000 = 118,500원 ✅
   - 매수 2: 118,500 - 5,000 = 113,500원 ✅
   - 매도 1: 123,500 + 5,000 = 128,500원 ✅
   - 매도 2: 128,500 + 5,000 = 133,500원 ✅

// 결과: 정확히 5,000원 간격 유지
```

### 2. 체결 후 주문 생성 (`handleFillEvent.ts`)

```typescript
// 매수 체결 후 매도 주문 생성
체결가: 118,456원
간격: 5,000원
매도가 = 118,456 + 5,000 = 123,456원
조정 후 = adjustToTickSize(123,456, "up") → 123,500원 ✅

// 매도 체결 후 매수 주문 생성
체결가: 128,789원
간격: 5,000원
매수가 = 128,789 - 5,000 = 123,789원
조정 후 = adjustToTickSize(123,789, "down") → 123,500원 ✅
```

## 🔧 주요 함수

### `adjustToTickSize(price, direction)`

```typescript
/**
 * 주어진 가격을 호가 단위에 맞춰 조정
 * @param price - 원본 가격
 * @param direction - "up" | "down" | "round"
 */

// 예시
adjustToTickSize(123,456, "round") // 123,500 (반올림)
adjustToTickSize(123,456, "down")  // 123,000 (내림)
adjustToTickSize(123,456, "up")    // 123,500 (올림)
```

### 조정 방향 선택 기준

- **매수 주문**: `"down"` - 낮은 가격으로 조정 (유리)
- **매도 주문**: `"up"` - 높은 가격으로 조정 (유리)
- **기준가 설정**: `"round"` - 반올림

## ⚠️ 주의사항

### 1. 간격 차이 발생 가능

```typescript
// 예시: 가격대가 바뀌는 경우
현재가: 51,000원 (호가 100원)
간격: 5,000원

매수 1: 46,000원 (호가 50원 구간)
매수 2: 41,000원 (호가 50원 구간)

// 실제 간격: 정확히 5,000원 유지 ✅
```

### 2. 그리드 간격 권장 사항

효율적인 그리드를 위해 **현재가 기준 호가 단위의 배수**로 설정 권장:

| 현재가 구간 | 호가 단위 | 권장 간격 예시 |
|:-----------|:---------|:-------------|
| 10만원 ~ 50만원 | 500원 | 5,000원, 10,000원 |
| 5만원 ~ 10만원 | 100원 | 1,000원, 5,000원 |
| 1만원 ~ 5만원 | 50원 | 500원, 1,000원 |
